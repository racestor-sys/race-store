# Race Store — موقع شحن الألعاب والاشتراكات

موقع عربي كامل (RTL) لواجهة شحن الألعاب والاشتراكات، بتصميم سباقات أسود × أحمر (Race Store)، وباقات لكل لعبة/خدمة.
كل باقة بتفتح محادثة واتساب برسالة جاهزة فيها الخدمة والباقة والسعر و ID اللاعب أو يوزر روبلوكس أو الإيميل (لو العميل كتبه).

> **الموقع المباشر:** https://racestor-sys.github.io/race-store/

## الألعاب والخدمات المتاحة حاليًا

- **فري فاير**: شحن ID، عضويات، شحن أكونت، دروب.
- **ببجي موبايل**: شحن شدات بالـ ID.
- **بيس (PES)**: شحن كوينز — أكونت فقط مع ربط حساب كونامي.
- **بلود سترايك**: شحن جولد بالـ ID + باسات وكروت.
- **روبلوكس**: شحن روبوكس بالـ يوزر + اشتراك شهري 1000 روبوكس.
- **تيك توك**: شحن كوينز بالـ يوزر (8 باقات من 70 لـ 5000 كوين).
- **اشتراكات**: يانجو بلاي، سبوتيفاي، شاهد، واتشيت، جيمناي، ChatGPT.

> التصميم جاهز لإضافة أي ألعاب أو خدمات تانية بسهولة من ملف الجافاسكربت.

## أرقام التواصل

كل الأرقام والروابط بتتظبط من مكان واحد في `assets/js/main.js`:

```js
const CONFIG = {
  whatsappNumber: "201021612723",        // واتساب أساسي بالصيغة الدولية
  displayPhone: "01021612723",           // الرقم كما يظهر للزائر
  backupWhatsappNumber: "201099163786",  // واتساب احتياطي
  backupDisplayPhone: "01099163786",
  telegramUser: "amk_race",              // تليجرام بدون @
};
```

- الواتساب الأساسي: **01021612723**
- الواتساب الاحتياطي: **01099163786**
- تليجرام: **@amk_race**

كل روابط الواتساب ورقم التواصل الظاهر في الموقع بيتحدّثوا تلقائيًا من الإعدادات دي.

## تعديل الباقات والأسعار

من نفس الملف `assets/js/main.js`، عدّل كائن `GAMES`:

- `freefire` → أقسام: `id` / `membership` / `account`
- `pubg` → قسم: `shards`
- `pes` → أقسام: `coins` / `players`
- `bloodstrike` → أقسام: `gold` / `passes`
- `roblox` → أقسام: `robux` / `membership`
- `tiktok` → قسم: `coins`
- `subscriptions` → أقسام: `platforms` / `ai`

كل باقة بالشكل ده:

```js
{ name: "110", unit: "جوهرة", price: 60, hot: true }
```

- `name`: اسم/كمية الباقة
- `unit`: الوحدة أو وصف الباقة
- `price`: السعر بالجنيه
- `hot: true`: يظهر عليها شارة «الأكثر طلبًا 🔥» (اختياري)
- `textName: true`: يكبّر الاسم النصي للباقات زي الاشتراكات والباسات

## إضافة لعبة أو خدمة جديدة

1. من `assets/js/main.js`، انسخ كائن لعبة (مثل `pubg`) جوه `GAMES`.
2. غيّر الـ `key` واسم اللعبة والأيقونة و `idLabel`.
3. أضف أقسام اللعبة جوه `categories` بنفس شكل `shards`.
4. اللعبة هتظهر تلقائيًا في اختيار الألعاب، والأقسام بتاعتها هتظهر تلقائيًا.
5. أضف روابط سريعة في الفوتر باستخدام `data-game-tab` و `data-package-tab`.

## إضافة ID اللاعب أو الإيميل

الزائر يقدر يكتب الـ ID أو يوزر روبلوكس أو الإيميل في الخانة اللي فوق الباقات، والقيمة بتتضاف تلقائيًا لروابط الواتساب.
- ألعاب الشحن بالـ ID بتقبل أرقام فقط.
- روبلوكس وتيك توك بيقبلوا يوزر الحساب (نص)، وبيس والاشتراكات بتقبل نص/إيميل.
- عند تغيير اللعبة بتتفضي خانة الـ ID عشان مايتبعتش ID لعبة غلط.
- لو الخانة فاضية، الرسالة بتطلب من العميل يبعت الـ ID أو بيانات التفعيل في الشات.
